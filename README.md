# 현장체험학습 안전 길잡이 3D

인천정각초에서 모래내시장역(인천 2호선)을 거쳐 시민공원역, 아인애비뉴 지하 2층 CGV 인천시민공원까지 걸어가며 안전 수칙을 익히는 3D 게임이에요.

- 게임: `index.html`
- 선생님 화면: `teacher.html` (반 만들기, 진행 상황·안전 점수 보기)
- 설정: `net-config.js` (`endpoint`: 기록 서버 주소, `multiplayer`: 함께 하기 켜기/끄기)
- 기록 서버: `backend/Code.gs` (Google Apps Script, 설치 방법은 파일 맨 위 설명)

## 함께 하기
같은 반 코드로 들어온 친구는 최대 30명까지 같은 공간에서 서로 보여요. 브라우저끼리 바로 연결해요(WebRTC). 처음 만날 때만 공개 중계소를 잠깐 써요.
주고받는 것: 위치·방향, 번호·별명, 장면, 안전 점수, 이모티콘 번호, 하이파이브. 자유 글은 보내지 않아요.
상호작용: 이모티콘 6가지(숫자 1~6), 가까이 간 친구와 하이파이브(E).

## 기록 서버가 터지지 않게
학생 한 명당 한 줄만 쓰고, 진행 기록은 캐시에 모았다가 1분마다 한 번에 시트에 써요.
가득 차면 가장 오래 안 쓴 기록·반부터 지우고, 60일 넘게 안 쓴 반은 매일 새벽 정리해요.

## 시험
- 혼자 자동 진행: `index.html?auto`
- 가짜 서버: `node backend/mock/server.js 8787` → `http://127.0.0.1:8787/index.html?ep=http://127.0.0.1:8787/api`
- 함께 하기(개발용): `?mp=반코드,번호,별명`
